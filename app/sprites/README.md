# Sprites (Daniel)

Drop PNGs here and the app uses them automatically; anything missing falls back to the
firmware's 1-bit placeholders (`js/sprites-builtin.js`).

| File | Form |
|---|---|
| `egg_a.png`, `egg_b.png` | egg |
| `baby_a.png`, `baby_b.png` | hatched chick |
| `sprinter_a.png`, `sprinter_b.png` | evolved from walking |
| `frost_a.png`, `frost_b.png` | evolved from sitting still |
| `glitch_a.png`, `glitch_b.png` | evolved from shaking |

- 32x32 px, transparent background, any colors (the phone isn't limited to 1-bit).
- `_a` / `_b` are the two animation frames.
- The screen is dark teal (`#0d2a36`), so keep outlines light.
- Original creatures only.
