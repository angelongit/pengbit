# Sprites (Daniel, W6)

Drop PNGs here and the app uses them automatically; anything missing falls back to the
firmware's 1-bit placeholders (`js/sprites-builtin.js`).

| File | Used for |
|---|---|
| `egg_a.png`, `egg_b.png` | egg |
| `baby_a.png`, `baby_b.png` | hatched chick |
| `sprinter_a.png`, `sprinter_b.png` | evolved from walking (phone) or taking breaks (desk) |
| `frost_a.png`, `frost_b.png` | evolved from sitting still (phone) or sitting upright (desk) |
| `glitch_a.png`, `glitch_b.png` | evolved from shaking (phone) or slouching (desk) |
| `scholar_*`, `hunchling_*`, `trail_mage_*`, `library_sage_*`, `static_mage_*` (`_a`/`_b`) | study evolutions from `ws/evolutions-recap` |
| `slouch_a.png`, `slouch_b.png` | Desk mode reaction while the owner slouches (shown by the floating window, `js/pip.js`) |
| `professor.png` | Professor Liveoak's portrait (loaded by `main.js`, falls back to the inline 16x16 face) |

- 32x32 px, transparent background, full color. `_a` / `_b` are the two animation frames.
- Drawn for the dark teal screen (`#0d2a36`): light outlines, dark navy hood, white face and belly.
- Original creatures only. Pebblebit is its own character; no franchise art, names or terms.
- Source: generated by `color_sprites.py` in this folder (`python3 color_sprites.py .`), then hand-editable in any pixel editor.
